# JARVIS Project

A personal engineering experiment exploring local-first AI systems architecture.

Created by Rob Cashman

## Purpose

JARVIS explores how reliable AI systems can be built through:

- modular architecture
- provider abstraction
- knowledge systems
- controlled execution
- human authorization
