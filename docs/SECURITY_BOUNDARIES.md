# Security Boundaries

## Principle

AI capability should not imply unrestricted authority.

## Data Boundary

Private knowledge remains separate from public artifacts.

## Reasoning Boundary

AI reasoning and system authority are separate concepts.

The ability to generate recommendations, analysis, or proposed actions does not
grant the ability to modify systems, access resources, or perform operations.

## Authorization Boundary

Actions require explicit approval mechanisms.

## Execution Boundary

Reasoning and execution are separate.

## Publication Boundary

Private development artifacts are reviewed before publication.
