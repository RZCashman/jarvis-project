# JARVIS Publication Model

## Principle

The public JARVIS repository is an independent engineering artifact.

It is not a mirror, export, or subset of the private JARVIS implementation.

## Private Repository

Location:
D:\JARVIS

Purpose:
Personal AI system development environment.

Contains:
- personal integrations
- private knowledge systems
- experimental components
- local configuration
- private workflows

## Public Repository

Location:
D:\JARVIS_PUBLIC

Purpose:
Document architectural concepts and publicly shareable examples.

Contains:
- sanitized code examples
- architecture documentation
- tests
- demonstrations
- design decisions

## Publication Rule

No file is transferred from private to public automatically.

Every published artifact must be intentionally reviewed.
